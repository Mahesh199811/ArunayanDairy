# Frontend

React + TypeScript + Vite customer app for ArunayanDairy.

Local API bases (see `src/services/api.ts`):

- User Service: http://localhost:5051
- Product Service: http://localhost:5296
- Order Service: http://localhost:5275

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. Login and product listing are wired; cart and order UI are not in this step.
