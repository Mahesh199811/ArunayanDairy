# ArunayanDairy

A production-style dairy platform structured around a frontend, backend services, serverless functions, Docker-based infrastructure, and documentation.

## Architecture

- Frontend
- Backend microservices
- Database and API integration
- Lambda/serverless workflows
- Containerized deployment setup

## Repository structure

- frontend/ – Web or mobile application frontend
- services/ – Domain-specific microservices
  - UserService/
  - ProductService/
  - OrderService/
- lambda/ – Serverless functions and event-driven handlers
- docker/ – Container and orchestration files
- docs/ – Architecture, API, and operational documentation
